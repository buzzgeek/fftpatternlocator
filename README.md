# fftpatternlocator
implementation of a working discrete fast fourier transfomation in godot which has native quaternion support - really fast transformation

The functions of interest all reside in the qft.gd file. To whom it might be of interest. This could be used for encoding decoding schemes that similarily have been implemented with complex numbers. However Quaternions have a certain charm, since 4 dimensions can be encoded relatively fast (eg bitmap).
